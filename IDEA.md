# My app

**Domain:**
Game record tracker

**User story:** 
As a game player, I need to see track how many matches I’ve played, how I’ve performed, and how my rating/MMR has changed over time, so that I can see whether I’m improving and decide what to practice next.

**What the user types or picks:**
The user types a match type, such as `solo`, and can filter the results by win or loss.
