Ship It by Noon: The one-hour Database App

3 points. Due Tuesday, November 24, 11:59 pm.

Today you build a small, real web app from your own idea, starting from an empty folder, by directing an AI coding assistant. The starter repository contains no app: only places for things, the rules your AI follows, and the location of the class database. The idea is yours. The code comes from you directing the AI. Running it, checking it, and fixing it is your job.

web/index.html  -->  server/server.js  -->  SQL Server (class server, your own <NetID>_myapp database)
the page             the middle tier        the data

Steps

Follow the README in the starter repository: github.com/billhowe/ship-it-by-noon. Be on UW Wi-Fi or the Husky OnNet VPN.

  1. Set up VS Code with GitHub Copilot (Agent mode), and make your own repository from the template.
  2. Choose an app domain: something you know or care about.
  3. Set up your laptop environment with one prompt: Node.js, your settings, and your own database <NetID>_myapp on the class server.
  4. Build your app from a user story: "As a ___, I need to ___, so that ___." First see it with made-up rows, then make it real with your own tables and data.

Extra: the README explains how to host your app permanently on UW's servers (vergil).
